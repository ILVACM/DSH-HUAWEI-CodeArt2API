什么是码道 CLI
产品概述
华为云码道CodeArts代码智能体CLI（CodeArts Agent CLI，简称码道CLI）是面向开发
者的智能编码助手，具备代码编写、代码分析、代码优化等全链路智能化能力。
码道CLI提供了终端交互界面（TUI）与命令行模式（CLI）双形态，无缝融入研发工作
流并适配多样场景。在无桌面环境中，TUI以可视化交互简化代码编写与调试，CLI则
通过命令实现快速编译，兼顾易用性与效率。
表1-1 TUI与CLI区别
特性 TUI（终端交互界面） CLI（命令行模式）
交互方式 对话框输入，可视化操作 直接传参数，一行命令执行
适用场景 交互式开发、代码编写与 脚本自动化、批量任务
调试
推荐人群 新手用户、日常开发 有命令行经验的开发者
支持的操作系统
● Windows：推荐使用Windows 11 (x64)；如果使用Windows 10 (x64)，系统版
本需为2019年及以上，建议升级至最新稳定版本。
● macOS：macOS 11及以上版本，兼容ARM64（Apple Silicon）架构。
● Linux：Huawei Cloud EulerOS 2.0、SUSE Linux Enterprise Server 12 SP5、
Ubuntu 18.04/20.04/22.04/24.04 LTS、Debian 10/11/12、CentOS 8、RHEL
8/9。
核心功能
● 命令覆盖：提供models（模型配置）、sessions（管理会话）等核心命令，支持
完整生命周期管控。
● 脚本化集成：支持通过命令参数直接传递任务，也可以将命令写入脚本文件（如
Shell脚本、Python脚本）自动执行，实现AI任务的自动化与批量处理。

2.2 授权
授权方式分为网页端登录授权和AK/SK鉴权授权两种。请根据你所使用的环境，按需
选择合适的方式。
网页端登录授权
仅支持TUI开发模式。如果你尚未登录华为云官网，且本地未配置任何AK/SK，可通过
以下方式完成授权。以Windows操作系统为例。
步骤1 在目标项目开发目录下，鼠标右键选择“在终端中打开”，自动唤起PowerShell窗
口。
步骤2 输入“codearts”命令并回车，将自动跳转至外部浏览器的华为云登录页面。
步骤3 输入你的华为云账号信息并登录，登录成功后系统自动完成授权。
----结束
AK/SK 鉴权授权
适用于TUI/CLI开发模式。AK/SK鉴权授权提供了进程级临时授权和系统环境变量永久
授权两种模式，以灵活适配不同场景。
● 进程级临时授权：仅在当前终端会话内生效，窗口关闭后自动失效。无需持久化
存储密钥，特别适合临时调试或在公共机器上进行测试，安全便捷。
● 系统环境变量永久授权：将鉴权信息写入系统Shell或Windows环境变量。新开终
端或重启设备后依然有效，适合个人本地长期开发使用，避免重复配置。
